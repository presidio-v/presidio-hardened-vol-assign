# Manuscript ↔ implementation consistency notes

Cross-check of the draft against the shipped tool (`presidio-hardened-vol-assign`
v0.2.0, unreleased). All items below are now **resolved** — either in the code
(folded into the unreleased v0.2.0) or in this manuscript edit.

## Resolved in the code (on `main`)
- **CLI command name** — `pva allocate-people` exists as a real subcommand
  (alias for `assign --model humanitarian`). ✓
- **NRGA fidelity** (§3.4) — canonical rank-biased roulette-wheel NRGA
  (Al Jadaan et al., 2008) implemented as `--solver nrga-ranked`; the prior
  uniform variant remains as `--solver nrga`. §3.4/§4 invoke it; §5.2 reports
  `nrga-ranked` as "NRGA". ✓
- **Sensitivity analysis** (§5.3, §6.4) — implemented as `pva sensitivity`
  (multiplicative ±10 %/±20 % perturbation of FIS output scores; reports the
  shift in NNS/MID/SM/HV). Previously slated for v0.3.0; brought into v0.2.0. ✓

## Resolved in this manuscript edit
- **Package/module paths** (§4.2, §4.4) — reworded to the real layout:
  `src/presidio_vol_assign/` with `domains/` adapters
  (`ed_staffing.py`, `humanitarian.py`) and `fis_humanitarian.py`. ✓
- **Reproducibility contract** (§4.5, §5.1, Code & Data Availability) — repointed
  from the non-existent `pva … --config v0.2.0/data/…yaml` to the real mechanism:
  seeded reproduction from CSVs, `pva benchmark` for tables, `pva show` for
  figures, and the committed `examples/` datasets. ✓
- **Statistical tests** (§5.2) — clarified that Shapiro–Wilk / paired t-tests are
  computed as post-processing (standard SciPy) on the emitted `benchmark_*.csv`;
  the tool produces the per-instance metrics, the tests are applied to them. ✓
- **Cross-machine reproducibility** (§5.4) — softened to same-environment
  bit-for-bit reproducibility for a fixed seed (the REP metric); the stronger
  cross-architecture / macOS claim is removed unless backed by an explicit
  cross-platform experiment. ✓

## Naming note (informational)
- Example datasets: `examples/small` is a 12-people / 3-centre toy for the worked
  example; the paper's "small case" (5 RC / 150 people) is `examples/paper_scale`,
  and the "large case" (10 / 300) is generated by `pva benchmark`. The manuscript
  now refers to `pva benchmark` + `examples/` rather than fixed `data/` paths.
