# Building the Systems (MDPI) manuscript — Paper B

`paper.tex` targets the official MDPI class for *Systems*
(`\documentclass[systems,...]{Definitions/mdpi}`). It is a **scaffold**: section
bodies are visible `\emph{[DRAFT ...]}` placeholders to be written as the RQ1–RQ3
runs land. Search `[DRAFT` to find every stub; none may remain at submission.

## Binaries kept out of git (repo no-large-binaries policy)

- **MDPI template logos** — `Definitions/logo-*.eps` / `logo-*.pdf` are git-ignored.
  Restore from the MDPI *Systems* LaTeX template (<https://www.mdpi.com/authors/latex>)
  or copy from `../../v0.2.0-mdpi/author/Definitions/`. The text template files
  (`mdpi.cls`, `mdpi.bst`, `journalnames.tex`, `chicago2.bst`) are committed.
- **Figures** — `../figures/*.pdf` are generated by `experiments/make_turbulence_figures.py`
  and git-ignored.

## Build

```bash
latexmk -pdf paper.tex   # needs Definitions/ logos present
```
