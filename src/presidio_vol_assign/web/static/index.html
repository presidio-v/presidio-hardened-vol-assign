Who goes where, after a disaster?

Relief planning rarely has one right answer. Helping the most vulnerable people, keeping journeys short, and not overwhelming any single centre pull against each other. This tool finds the set of allocations where you cannot improve one goal without giving up another — then lets you walk along that set and see the trade-off for yourself.

What the numbers mean

    

      

        
The trade-off set

        

          Every point in the set is an allocation that no other allocation beats on
          every goal at once. Moving along the set means deliberately choosing what to
          give up. That choice belongs to a human planner, not to the algorithm.
        

      

      

        
Fuzzy scoring

        

          Words like "very vulnerable" or "poor road access" are not sharp thresholds.
          Fuzzy inference systems turn those judgements into scores, so the model can
          weigh them without pretending they are exact.
        

      

      

        
Synthetic data only

        

          Every instance here is generated from the settings and the seed. Nothing is
          uploaded and nothing is stored. Change the seed to see a different affected
          area with the same character.
